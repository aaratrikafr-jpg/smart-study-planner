# Smart Study Planner 🧠📚  
A student-built productivity web app powered by real feedback

## 🚀 Project Overview  
Smart Study Planner is an interactive web application designed to help students plan their study sessions effectively using time-based scheduling, reminders, and a clean, colorful UI. I built this project after noticing that most students struggle with structuring their study time and staying consistent.

I designed a Streamlit-based study planner that functions as a behavior consistency system. The system integrates structured planning, daily behavioral reflection, and adaptive iteration rules to help students overcome procrastination and build consistency. Based on user feedback and short-term testing, the planner adapts tasks when patterns of avoidance or burnout appear, encouraging sustainable study habits rather than rigid scheduling.

What makes this project special is that it was iteratively improved using real student feedback and deployed publicly.

---

## 🎯 Problem Statement  
Many students:
- Study without a clear timetable  
- Forget revision sessions  
- Feel overwhelmed by boring or cluttered planners  

Existing planners are either too complex or not student-friendly.

---

## 💡 My Solution  
I built a simple, visual, and interactive study planner that allows students to:
- Create time-wise study schedules  
- Categorize sessions (Study, Revision, Break)  
- Receive daily reminders  
- View their plan in a color-coded table  
- Stay motivated using a friendly, aesthetic UI  

---

## 🛠️ Key Features  
- ⏰ Time-based study scheduling  
- 🎨 Color-coded timetable (Study / Revision / Break)  
- 🔔 Custom daily study reminders  
- 📊 Interactive schedule table  
- 🐱 Fun UI elements (stickers & emojis for motivation)  
- ☁️ Publicly deployed web app  

---

## 🧪 User Testing & Feedback  
I shared the app with 10+ students and collected feedback directly through the app.

### What users wanted:
- Timers and reminders  
- More visual and colorful UI  
- Clear timetable view  

### What I did:
- Implemented reminders  
- Designed a table-based schedule view  
- Improved UI visibility across devices  

All requested features were implemented successfully.

---

## 🧑‍💻 Tech Stack  
- Frontend & Backend: Streamlit (Python)  
- Data Handling: Pandas  
- State Management: Streamlit Session State  
- Deployment: Streamlit Cloud  
- Version Control: Git & GitHub
